# YouTube Bulk Unsubscribe Script

## Purpose

A simple script to unsubscribe from all YouTube channels quickly using the browser console.

## Steps

1. Go to:
   https://www.youtube.com/feed/channels

2. Open Developer Console:

   * Chrome: Ctrl + Shift + J
   * Or: Right click on the page → Inspect → Console tab

3. Paste the script from `script.js`

4. Press Enter and let the browser suffer for my past decisions

   Start fixing your life. Or at least your subscriptions 🙄
